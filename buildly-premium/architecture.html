🏗️ Arquitetura em Camadas

📊 Core Data Model (IEvent → IObjective → IDecision)

IEvent

Registro imutável de mudança no sistema

Stored: PostgreSQL Event Store (append-only)

id: UUID
type: EventType
aggregate_id: UUID
context: {...}
data: {...}
created_at: ISO 8601
version: integer

📌 Exemplo: MATERIAL_DELAY → "Cimento chegou 15 dias atrasado"

IObjective

Meta mensurável da obra

Stored: PostgreSQL Objective Store

id: UUID
obra_id: UUID
description: string
domain: execução|qualidade
primary_metric: {...}
start_date: DATE
end_date: DATE
status: active|completed

📌 Exemplo: "Concluir Bloco A até 31/8 com 100% qualidade"

IDecision

Registro de escolha com contexto e resultado

Stored: PostgreSQL Decision Store + Training IA

id: UUID
obra_id: UUID
event_id: UUID
domain: operacional|estratégico
options: [{...}]
chosen_option: string
roi: numeric
confidence: 0-1

📌 Exemplo: Escolher entre esperar, importar ou reordenar atividades

🔄 Material Delay Workflow (4-Week Pilot)

1️⃣

Week 1 — Setup & Baseline

Infrastructure, historical data loading, baseline predictions generated, gestores trained & signed off

2️⃣

Week 2-3 — Soft Launch (Observation Only)

Daily predictions generated, gestores observe (no decisions), system records all alerts, performance metrics tracked

3️⃣

Week 4-5 — Active Phase (Live Decisions)

Gestores approve/reject alerts, feedback recorded for model learning, actual outcomes tracked, ROI calculated

4️⃣

Week 6 — Analysis & Go/No-Go

Final metrics calculated, per-site ROI breakdown, model performance report, enterprise rollout decision
