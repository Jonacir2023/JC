  • Continuous feedback loop
  • Exponential optimization

Architecture in Layers

Core Data Model

The flow: IEvent → IObjective → IDecision. Immutable, context-rich, learnable.

IEvent

Immutable record of system change

Stored: PostgreSQL Event Store (append-only)

id: UUID
type: EventType
aggregate_id: UUID
context: {obra_id, ...}
data: {payload}
created_at: ISO 8601

IObjective

Measurable project goal

Stored: PostgreSQL Objective Store

id: UUID
obra_id: UUID
description: string
domain: execução|qualidade
primary_metric: {...}
start_date: DATE
end_date: DATE

IDecision

Choice record with outcome

Stored: PostgreSQL + Training data for IA

id: UUID
obra_id: UUID
event_id: UUID
domain: operacional|estratégico
options: [{...}]
chosen_option: string
roi: numeric
