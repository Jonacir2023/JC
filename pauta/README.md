# 📋 Pauta — Gestão de Obra

App web para gestão de pautas de reuniões, com Kanban interativo, calendário e dashboards.

## 🎯 Funcionalidades

- **Pauta** - Reuniões e pautas com contadores e Kanban
- **Cadastro** - Gerenciamento completo de assuntos
- **Calendário** - Visualização de eventos por mês
- **Resumo** - Análise semanal e mensal com rankings
- **Dashboard** - Visão geral da obra com gráficos
- **Captura de Imagem** - Download da pauta como PNG
- **Sincronização** - Integração com Google Sheets

## 🚀 Acesso

Acesse a aplicação em: **https://jonacir2023.github.io/pauta/**

## 💾 Dados Locais

Todos os dados são salvos em localStorage do navegador. Para sincronizar com Google Sheets, configure a URL da Google Apps Script no código.

## 🛠 Desenvolvimento

Para modificar o app, edite o arquivo `index.html` que contém HTML, CSS e JavaScript integrados.

## 🔧 Configuração Inicial

1. Abra o app no navegador
2. Clique em ⚙️ para configurar o nome da obra
3. Comece a adicionar assuntos na aba "Cadastro"
4. Use a aba "Pauta" para reuniões
